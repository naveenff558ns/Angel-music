🎧 ANGEL Music

Music Beyond Borders · Feel More.

ANGEL Music is a music app project inspired by the elegant, immersive experience of Apple Music. It aims to combine a premium dark interface, beautiful album artwork, personalised playlists, and a smooth listening experience in one place.

«Discover music. Feel every moment.»

---

✨ Features

- 🎨 Premium UI — Modern, Apple Music-inspired design.
- 🌑 Dark Aesthetic — A moody interface with elegant pink accents.
- 🎵 Music Library — Browse songs, albums, artists, and playlists.
- 💖 Favourites — Keep your favourite music close.
- 🎧 Now Playing — An immersive music player interface.
- 📝 Lyrics — A planned feature for following along with songs.
- 🔗 Spotify Integration — Planned playlist discovery and integration using official Spotify APIs, subject to API availability and limitations.
- 📱 Android Support — Designed with Android devices in mind.

Feature availability depends on implementation and supported third-party APIs.

🖤 Design Philosophy

ANGEL Music focuses on three principles:

- Minimalism: Keep the interface clean and distraction-free.
- Emotion: Make music feel personal through artwork and atmosphere.
- Elegance: Combine refined typography, smooth interactions, and a premium dark theme.

🚀 Getting Started

1. Download the Project

Download or clone this repository:

git clone https://github.com/YOUR-USERNAME/Angel-Music.git

Replace "ANGEL" with your GitHub username.

2. Open the Project

Open the downloaded project in a compatible Android development environment.

3. Configure Dependencies

Install the required Android SDK and Gradle versions specified by the project.

If Spotify integration is enabled, configure the required developer credentials securely. Never commit API secrets or private credentials to the repository.

4. Build the App

Once the Android project and build configuration are verified, build the debug APK using the project's Gradle wrapper:

./gradlew assembleDebug

On Windows, use:

gradlew.bat assembleDebug

The APK is typically generated under:

app/build/outputs/apk/debug/

The exact location depends on the project's module and build configuration.
